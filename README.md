# Phone Flip Guess Game

This is a mobile game where the user holds up the phone and others have to give clues about what word is displayed on the screen. 

The game is played in landscape.

After choosing a category, a Ready, 3, 2, 1 countdown timer is displayed and after the timer the game begins.
A word and a continuous 1 minute timer starts if the word is guessed the user flips the phone down to indicate a correct guess.
The user flips the screen up to indicate a pass. The scored is tracked by the number of correct guesses.

There should be several different popular categories to choose from to begin the game.
